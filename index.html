🤖 Guía de Publicación en Google Play Store

Esta aplicación incluye la configuración completa con Capacitor Android para generar el paquete oficial .aab (Android App Bundle) requerido por Google Play Console.

  1. Instalar Dependencias: npm install
  2. Inicializar Android: npx cap add android
  3. Sincronizar Recursos: npx cap sync android
  4. Abrir en Android Studio & Generar Bundle (.aab): npx cap open android
